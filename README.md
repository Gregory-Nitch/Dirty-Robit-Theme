# Dirty Robit Theme
A dusty VS Code theme for hardworking people. It may look a little dirty, but it is easy on the eyes. Now has non dusty/brown variants.
![Dirty Robit Theme Example](https://raw.githubusercontent.com/Gregory-Nitch/Dirty-Robit-Theme/main/Theme_Example.webp)

## Variants
- **Dirty Robit Theme**: The original warm, dusty palette.
- **Dirty Robit Darker**: A darker version of the original dusty palette, think mud.
- **Dirty Robit Brightened**: A brighter version of the original dusty palette with brighter text and backgrounds for bright rooms.
- **Dirty Robit Washed**: Neutral gray backgrounds with the original text and accent colors.
- **Dirty Robit Washed Darker**: A darker version of the neutral gray palette.
- **Dirty Robit Washed Brightened**: A brighter version of the neutral gray palette with brighter text and backgrounds for bright rooms.

## Inspiration

### Requirements
- **Visual Studio Code** (`^1.125.0`) — required to use the theme or test changes via the Extension Development Host (`F5`). No build step or runtime dependencies are needed to edit the theme JSON files.
- **Node.js & npm** (includes `npx`) — required for versioning (`npm version`) and packaging the extension.
- **`@vscode/vsce`** — VS Code Extension Manager used to package `.vsix` releases (can be run directly via `npx @vscode/vsce package`).
